## Games & roleplay

- **[RP Reel](https://github.com/hilsetapp/rp-reel)** - turns roleplay server logs and video into a timeline of moments, clips without re-encoding, and stats. Plugins for SA-MP, RAGE MP, and FiveM.
- **[GTA San Andreas Mod Manager](https://github.com/hilsetapp/sa-mod-manager)** - enable or disable mods, spot conflicts and file replacements before launch, and manage profiles. Windows app.
- **[SA-MP Pulse](https://hilsetapp.github.io/samp-pulse/)** - live player counts for 1,200+ SA-MP and open.mp servers, with 24-hour history, filters, and search. Open data, no login.
- **[Gtarp UI kit](https://hilsetapp.github.io/Gtarp-ui-kit/)** - ready-made GTA RP interfaces for inventory, HUD, chat, and phone, with three skins each. Two files, no build step. For RAGE MP, alt:V, and other CEF-based clients.
- **[RAGE Sim](https://github.com/hilsetapp/rage-sim)** - browser-based RAGE MP emulator with a canvas city, bots, and day/night cycle. Runs client code without changes.
- **[GTARP Vue Starter](https://github.com/hilsetapp/GTARP-Vue-Starter)** - Vue 3, Vite, TypeScript, and Pinia starter for GTA RP servers. Typed CEF events for UI work without launching the game.
- **[The New Z](https://dayz-site-two.vercel.app)** - website for a DayZ PvP server, with news, rules, and a join guide.

## Media & TV

- **[Lampa Setup Lab](https://hilsetapp.github.io/Lampa-Setup-Lab/)** - Lampa extension catalog with device filters, setup guides, and clear testing notes. [Source](https://github.com/hilsetapp/Lampa-Setup-Lab).

## Tools

- **[Repo Reel](https://hilsetapp.github.io/repo-reel/)** - turns a public GitHub repository into a short video with README details, code, stars, and recent commits. [Source](https://github.com/hilsetapp/repo-reel).
- **[Bus Factor Radar](https://hilsetapp.github.io/bus-factor-radar/)** - shows public maintainer and activity signals for npm, Go, and Python dependencies. An indicator, not an audit. [Source](https://github.com/hilsetapp/bus-factor-radar).
- **[GitHub Wrapped 2026](https://hilsetapp.github.io/Wrapped-2026/)** - animated year-in-code story and shareable poster. No login or tracking.
- **[Liquid Glass Studio](https://hilsetapp.github.io/Liquid-glass-studio/)** - preview glass effects on cards, buttons, and navigation, then copy CSS, variables, or Tailwind. [Source](https://github.com/hilsetapp/Liquid-glass-studio).
- **[YouTube Fix](https://github.com/hilsetapp/youtube-fix/releases/latest)** - one-click repair for YouTube, Telegram, and Discord, with automatic strategy selection, logs, and DNS helper. Windows app. Not a VPN; other traffic is left alone.
- **[discord-fix](https://github.com/hilsetapp/discord-fix/releases/latest)** - one-click Discord connection repair. Windows app. Not a VPN or proxy; other traffic is left alone.
- **[Handoff](https://github.com/hilsetapp/Handoff)** - carries project decisions, failed approaches, test status, and next steps between coding sessions.

Issues and feedback are welcome.
