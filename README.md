# hilsetapp

I build open-source tools: web apps, desktop utilities and scripts. Mostly small things that solve one real problem well.

## Games & roleplay

- **[RP Reel](https://github.com/hilsetapp/rp-reel)** - журнал событий RP-сервера и видеозапись становятся нарезкой моментов одной кнопкой: таймлайн, клипы без перекодирования, статистика. Плагины для SA-MP, RAGE MP и FiveM.
- **[Менеджер модов GTA San Andreas](https://github.com/hilsetapp/sa-mod-manager)** - включай и выключай моды одним переключателем, конфликты и замену стандартных файлов видно до запуска игры, профили сборок. Приложение для Windows.
- **[SA-MP Pulse](https://hilsetapp.github.io/samp-pulse/)** - live player counts for 1200+ SA-MP and open.mp servers: 24h history, filters, search. Open data, no login.
- **[Gtarp UI kit](https://hilsetapp.github.io/Gtarp-ui-kit/)** - ready-made interfaces for GTA RP servers: inventory, HUD, chat, phone, three skins each. Two files, no build step, works with RAGE MP, alt:V and anything with CEF.
- **[RAGE Sim](https://github.com/hilsetapp/rage-sim)** - RAGE MP emulator in the browser: canvas city, bots, day and night. Your client code runs without changes.
- **[GTARP Vue Starter](https://github.com/hilsetapp/GTARP-Vue-Starter)** - starter for GTA RP servers: Vue 3 + Vite + TypeScript + Pinia. Typed CEF events, UI development without launching the game.
- **[The New Z](https://dayz-site-two.vercel.app)** - website of a DayZ PvP server: news, rules, join guide.

## Media & TV

- **[Lampa Setup Lab](https://hilsetapp.github.io/Lampa-Setup-Lab/)** - каталог расширений Lampa с фильтрами по устройствам, инструкциями и честными статусами проверки. [Исходный код](https://github.com/hilsetapp/Lampa-Setup-Lab). Сайт открывается сразу, подключать ничего не нужно.

## Tools

- **[Repo Reel](https://hilsetapp.github.io/repo-reel/)** - turns a public GitHub repository into a 30-second video with README details, code, stars and recent commits. [Source](https://github.com/hilsetapp/repo-reel).
- **[Bus Factor Radar](https://hilsetapp.github.io/bus-factor-radar/)** - local-first maintainer and activity signals for npm, Go and Python dependencies. It shows what the public data can support, not a security verdict. [Source](https://github.com/hilsetapp/bus-factor-radar).

- **[GitHub Wrapped 2026](https://hilsetapp.github.io/Wrapped-2026/)** - your year in code as an animated story and a shareable poster. No login, no tracking.
- **[Liquid glass studio](https://hilsetapp.github.io/Liquid-glass-studio/)** - design the iOS liquid glass effect visually, copy production CSS or Tailwind in one click.
- **[YouTube Fix](https://github.com/hilsetapp/youtube-fix/releases/latest)** - одна кнопка, и YouTube, Telegram и Discord открываются снова. Автоподбор стратегии, журнал, DNS-помощник. Не VPN, остальной интернет не трогает. Windows.
- **[discord-fix](https://github.com/hilsetapp/discord-fix/releases/latest)** - одна кнопка, и Discord снова работает. Не VPN и не прокси, остальной интернет не трогает. Приложение для Windows.
- **[Handoff](https://github.com/hilsetapp/Handoff)** - portable working context for AI coding agents: save once, every agent picks it up.
